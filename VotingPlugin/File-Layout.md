# File Layout

> **Release defaults:** [VotingPlugin 7.1.1 resources](https://github.com/BenCodez/VotingPlugin/tree/7.1.1/VotingPlugin/src/main/resources). The [`master` resources](https://github.com/BenCodez/VotingPlugin/tree/master/VotingPlugin/src/main/resources) are development defaults and may contain unreleased keys or behavior.
{.is-info}

## Backend files

Path: `plugins/VotingPlugin/`

![Example VotingPlugin data folder on a backend server](https://i.imgur.com/NRZbbcW.png)

| File/folder | Purpose |
|---|---|
| `Rewards/` | Reusable and generated reward files. |
| `TopVoters/` | Stored previous TopVoter results when the related storage options are enabled. |
| `BungeeSettings.yml` | Backend proxy communication, server name, and proxy-related behavior. |
| `Config.yml` | Main storage, formats, reminders, reward processing, and general behavior. |
| `GUI.yml` | Player/admin GUI configuration. |
| `Shop.yml` | VoteShop categories, buttons, limits, and rewards. |
| `ServerData.yml` | Internal vote-party/top-voter state; do not edit manually. |
| `SpecialRewards.yml` | VoteMilestones, VoteStreaks, vote parties, NameMC, and top-voter awards. |
| `Users.db` | SQLite player data when `DataStorage: SQLITE`. |
| `VoteSites.yml` | Vote sites, service names, delays, and per-site rewards. |

## Reward folder

Path: `plugins/VotingPlugin/Rewards/`

![Example contents of the VotingPlugin Rewards folder](https://i.imgur.com/etHNpAA.png)

| Entry | Purpose |
|---|---|
| `DirectlyDefined/` | Generated representation of inline rewards. Do not edit; change the source configuration. |
| user-created `.yml` files | Reusable rewards referenced without the extension. |
| generated examples | Reward syntax examples generated by the installed build, when present. |

See [Reward Files](/VotingPlugin/Reward-File) and [AdvancedPriority Rewards](/VotingPlugin/AdvancedPriority-Rewards).

## Proxy files

Path: `plugins/VotingPlugin/` on BungeeCord or Velocity.

![Example VotingPlugin data folder on a proxy server](https://i.imgur.com/RYVmnhM.png)

| File | Purpose |
|---|---|
| `bungeeconfig.yml` | Proxy database, routing, communication method, caches, totals, and multi-proxy settings. |
| `nonvotedplayerscache.json` | Recently seen players used by joined-player validation when JSON storage is selected. |
| `secretkey.key` | Encryption material for SOCKETS and optional plugin-message encryption. Copy only through a secure channel and keep it private. |
| `votecache.json` | JSON vote cache when the proxy is not configured to use the SQL vote cache. |

Do not manually merge generated files from a newer development build into release 7.1.1. Compare keys and migrate intentionally.
